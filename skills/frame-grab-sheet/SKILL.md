# 视频抽帧分镜总览图

## 目标

只使用视频真实画面生成一张最终比例严格为 3:4 的总览图。画面按时间顺序左→右、再上→下排列；不解释、不重绘、不补帧、不添加视频中不存在的内容。

## 产品替换模式

当用户要求“换产品”“产品替换”“基于原分镜换款”或提供原分镜图与产品参考图时，启用本模式：

### 输入优先级

1. **原分镜图/原视频**：锁定构图、人物、手部动作、镜头角度、景别、景深、光影、背景、时间顺序和所有非产品内容。
2. **上传的产品参考图**：作为唯一产品资产来源，只决定产品的真实瓶身比例、颜色、瓶盖、标签文字、材质和包装外观。
3. **文字提示**：只用于约束合成关系，不得重新设计广告画面或补充新元素。

### 替换规则

- 逐帧执行“只替换产品主体”；原分镜中没有产品的帧禁止新增产品。
- 保留上传产品的真实外观，不把产品改造成原产品的颜色、瓶型或瓶盖；只根据原镜头改变它的透视、尺度、朝向、景深、遮挡和光照。
- 对每一帧匹配原镜头的产品位置、透视角度、手指接触点、遮挡边界、反射光方向、阴影接触和虚化程度。
- 人物、手部数量与姿势、皮肤、服装、背景、道具、摄影机位置、镜头运动、焦段感和光影方向均视为锁定内容。
- 产品必须随原视频动作连续移动；禁止漂浮、穿透手指、改变握持关系、突然变大/变小或在相邻帧跳位。
- 末尾包装镜头必须锁定原包装的摆放关系、产品与包装盒的左右位置、接触面和收尾构图；若用户要求使用上传包装图，包装图同样只作为产品资产，不得改变原构图。

### 产品替换验收

- 对照原分镜逐帧检查：非产品区域像素级构图是否保持，人物和手部轮廓是否改变。
- 检查产品是否仅在原视频出现的时间进入画面，是否在每个镜头中保持正确尺度、朝向和遮挡。
- 检查标签文字是否来自产品参考图，禁止模型编造、重排或替换品牌文字。
- 检查产品材质是否受到原场景光线影响：反射、透光、高光、阴影和景深必须与原镜头一致。
- 不要把带有黑色参数区、白色文字或表格的标注分镜图作为唯一视觉参考；它会被模型误认为画面内容。视觉输入优先使用无文字原分镜图，参数单独作为文字控制。

## 工作流

1. 检查输入视频、时长、原始宽高比、帧率和可读取性。若存在多个视频，先询问是否合并；默认只处理用户指定的视频。
2. 根据时长自动决定抽帧数量：短视频优先覆盖完整动作变化，中长视频保持均匀时间采样，超长视频控制总图可读性。除非用户指定，默认按时间均匀抽帧，并让首帧和尾帧都进入序列。
3. 用 `scripts/make_contact_sheet.py` 生成抽帧总览。优先调用本 Skill 自带脚本；只有脚本无法读取输入时才改用 ffmpeg/Pillow 等等价工具。
4. 逐项验收：时间顺序、帧数、原比例、主体是否被裁切、是否变形、是否有白边/黑边/透明空区、帧间距是否为0、外框是否为3:4。
5. 输出最终 PNG，并同时保留抽帧目录和可复现的参数记录（如用户需要）。不要把抽帧目录或参数记录当作总览图替代品。

## 排版规则

- 画布固定为宽:高 = 3:4；默认使用足够大的输出尺寸，避免后期缩放后帧细节不可读。
- 采用最大化横向阅读的紧凑网格：能增加同一行帧数时不竖向堆叠；从左到右读完一行后再读下一行。
- 默认采用 justified rows：每行帧都直接贴合并填满画布宽度，行高按原视频比例自适应，行与行之间为0。这样可以同时满足严格3:4、无留白、无变形；不同视频或不同抽帧数量下，各行高度可能不同。
- 如果用户明确要求所有帧全局完全同尺寸，改用统一帧高/统一帧宽的整数网格，并明确说明：任意抽帧数量下可能无法同时严格满足3:4；禁止用裁切、拉伸或背景填充强行补齐。
- 禁止固定方形卡片、白色背景、外边距、边框、标题、编号贴纸、装饰线、阴影和间隔。
- 每一帧保留原视频宽高比；不得裁切主体、改变画幅、拉伸变形或用背景填充统一尺寸。
- 文件名可使用 `Frame001`、`Frame002` 等内部排序，但最终画面不叠加文字。用户另行要求标签时，标签不得遮挡视频内容且必须显式确认。

## 抽帧策略

- 默认使用时间均匀采样；对于动作密集段，可在不改变整体时间顺序的前提下提高该段采样密度。
- 用户说“每一帧”“逐帧”“全部帧”时，必须使用脚本的 `--every-frame`，读取视频流中的全部帧，不得用均匀抽样替代。
- 抽帧数量应由视频时长、动作变化和目标可读性共同决定，不盲目每帧抽取。
- 帧序列必须保留真实时间先后。若使用场景切换检测或关键帧抽取，仍要按时间排序，并在交付说明中记录策略。
- 不能用 AI 生成画面补足缺失帧，也不能用插帧、超分或修复改变画面内容，除非用户明确要求。

## 几何冲突处理

“严格3:4、所有帧同尺寸、原比例、0间距、无留白”对任意帧数并非总可同时实现。遵循以下优先级：

1. 不改变真实画面内容和原比例。
2. 不裁切、不变形、不填充背景、帧间距为0。
3. 严格输出3:4；为此默认允许各 justified row 的帧高不同，但同一行内高度一致。
4. 只有用户明确要求全局同尺寸时，才牺牲严格整数网格的3:4精确度，并报告实际比例。

## 失败诊断

- 出现白色或黑色大块：检查是否使用了固定画布、方形缩略图或 `contain` 填充；改用按行比例缩放。
- 出现帧间隙：检查拼接坐标是否有四舍五入误差；使用累计整数坐标并让下一帧从上一帧终点开始。
- 出现裁切或主体缺失：检查是否使用 `cover`；改用保持比例的缩放。
- 出现变形：检查是否同时强制指定宽和高；仅指定行高或按源比例计算宽度。
- 阅读方向错误：检查是否按列拼接；必须按行写入，排序键为 `(row, column)`。
- 外框不是3:4：检查输出尺寸和最后一行布局；脚本必须在保存前验证 `width / height = 3 / 4`。

## 交付

交付至少包含一张 PNG 总览图。简要说明视频名称、抽帧数、采样方式、输出尺寸，以及是否使用了 justified rows。不要用文字总结视频内容来代替图像。
