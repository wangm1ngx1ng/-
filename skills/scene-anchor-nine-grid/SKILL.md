# 场景锚定九宫格分镜

## 1. 职责边界

本 Skill 只负责：

- 场景空间母版图与场景锚定参数卡。
- 纯空场景 3×3 九宫格 Next Scene 调度板。
- 多人物场景的人物站位连续性图。
- 动作与道具连续性图。
- 单张 16:9 关键帧和图生视频配图投喂表。
- 场景拓扑、遮挡关系、相对位置、光线方向和机位连续性检查。

本 Skill 不负责：

- 剧本改编、爆款研究、导演圣经、风格 DNA、声音后期和完整短剧方案。
- 角色资产库、全剧资产库和分集生产包。
- 把 `C01`、`S01`、`KF-01` 等内部编号交付给用户。

遇到完整剧本生产、电影级 AI 短剧方案或导演 Skill 任务，使用“电影级导演数字分身（开智版）”；不要把本 Skill 的九宫格规则复制到导演 Skill。

## 2. 触发条件

用户出现以下需求时使用本 Skill：

- “按通用九宫格模板处理”。
- “生成 3×3 专业电影场景九宫格”。
- “场景锚定”“Next Scene 调度板”“同一场景多机位”。
- “根据剧本段落做场景图/分镜图/关键帧”。
- “检查九宫格空间是否对得上、门窗桌椅是否漂移”。

如果用户只要一个普通单镜头分镜，不强行生成九宫格；如果用户明确要求九宫格，只给九宫格相关内容。

## 3. 核心原则

1. 先锁三维空间，再改变摄影机；不是为每个宫位重新设计一个场景。
2. 全局场景真相只写一份：固定物件、拓扑关系、时间、天气、光线、材质和空间比例必须原样继承。
3. 每格只改变摄影机位置、朝向、高度、景别、焦段和景深；不能改变物品真实位置。
4. 物品可以因为机位变化被遮挡、裁切或变小，但不能移动、镜像、替换、增减或穿模。
5. 不为某一个宫位单独增加禁止项。发现某格错误时，优先修复全局场景拓扑和机位定义。
6. 近景和特写仍然继承同一场景母版；看不见某个锚点不代表锚点消失。
7. 文字标题不交给模型稳定生成。优先输出无字版，并在文件名或后期叠加 `Next Scene1` 至 `Next Scene9`。
8. 严格三维连续性优先使用一张纯空场景母版图作为主参考，再生成九宫格；纯文字九宫格只作为调度板。

## 4. 工作流

### 第一步：提取场景锚定参数卡

从用户的剧本段落中只提取空间和连续性信息，不改写剧情：

```text
场景中文名称：
内外：
地点与时代：
时间、天气与光线：
空间中心点：
Anchor A 左侧固定锚点：
Anchor B 右侧固定锚点：
Anchor C 远处固定锚点：
Anchor D 前景地面或动作锚点：
固定物件清单：
固定物件之间的相邻关系：
人物数量与初始站位：
人物视线与行动方向：
禁止变化：
允许变化：
画幅：16:9 横屏
总画布：3×3 九宫格
```

必须补全“相邻关系”，例如：

```text
左侧房门紧贴左墙；右侧窗户嵌在右墙；两张桌子沿后墙左右排列；两台电脑分别位于对应桌面中央；人物活动通道位于两张桌子之间。
```

不能只写“房间里有门、窗、桌子”，否则模型会把物品当成可自由移动的装饰。

### 第二步：生成纯空场景母版

先生成一张 16:9 横屏、无人物、无动作、无可读文字的场景母版图。母版必须清楚看见完整空间、固定物件和中心活动区。母版不是九宫格，不要加入人物或剧情动作。

### 第三步：生成纯空场景九宫格

将场景母版的全部固定内容原样放入九宫格提示词，只允许改变摄影机。默认九格机位如下：

1. `Next Scene1`：原位正面建立，全景或中远景。
2. `Next Scene2`：摄影机向左平移，保持同一水平高度。
3. `Next Scene3`：摄影机向右平移，保持同一水平高度。
4. `Next Scene4`：从原轴线向左旋转约45度，显示侧向空间关系。
5. `Next Scene5`：高位俯拍，确认人物和物件的平面位置。
6. `Next Scene6`：低机位仰拍，确认地面、脚步和空间压迫关系。
7. `Next Scene7`：广角远景，完整回收场景全貌。
8. `Next Scene8`：局部近景或特写，继承同一空间轴线，不改变物件位置。
9. `Next Scene9`：回到原位或接近原位，作为连续性回收帧。

### 第四步：人物站位与动作道具

只有当人物关系或动作因果重要时，才追加：

- 人物站位九宫格：锁人物数量、服饰、相对位置、视线和进出方向。
- 动作道具九宫格：只表现一个动作链，例如“抬手 → 接触 → 收回”。

不把人物、动作、道具和场景混成一张提示词。场景先稳定，再叠加人物，再叠加动作。

### 第五步：裁切单张关键帧

九宫格是调度板，不直接作为视频模型的唯一参考图。完成九宫格后：

1. 选择对应宫位，裁成单张 16:9 横屏关键帧。
2. 用中文命名，例如“场景一机位八局部近景”。
3. 在配图表中写明主参考、辅助参考和上传顺序。
4. 关键帧优先作为视频模型主参考，场景母版、人物图和道具图作为辅助参考。

## 5. 固定输出格式

### 只要提示词时

用户说“只给九宫格场景提示词”“不要解释”“不要生成图片”时，只输出一段完整可复制提示词，不输出导演分析、剧本诊断或视频方案。

### 要完整分镜包时

输出一个独立 Markdown 文档，顺序固定为：

1. `场景锚定参数卡`。
2. `纯空场景母版图提示词`。
3. `纯空场景九宫格提示词`。
4. `人物站位九宫格提示词`，无多人或用户未要求时写“不适用”。
5. `动作道具九宫格提示词`，无动作道具需求时写“不适用”。
6. `九格机位功能表`。
7. `单张关键帧裁切与命名表`。
8. `图生视频配图投喂表`。
9. `连续性检查与失败降级方案`。

不得混入导演圣经、爆款分析、角色资产库、声音后期或完整剧本改编。

## 6. 通用九宫格提示词模板

```text

九格只改变摄影机，不改变场景中的物品真实位置。物品可以因透视、遮挡、裁切和景别变化而部分不可见，但不能移动、镜像、替换、增减、旋转到不合逻辑的位置或穿模。门窗、墙体、桌椅、道路、树木、地面纹理、光线方向、阴影方向、时间和天气完全一致。

九格机位：
Next Scene1：原位正面建立，全景或中远景；
Next Scene2：摄影机向左平移，水平高度不变；
Next Scene3：摄影机向右平移，水平高度不变；
Next Scene4：摄影机向左旋转约45度，显示侧向空间关系；
Next Scene5：高位俯拍，确认平面位置；
Next Scene6：低机位仰拍，确认地面和压迫关系；
Next Scene7：广角远景，回收完整空间；
Next Scene8：局部近景或特写，只放大既有物件，不移动物件；

```

## 7. 人物站位九宫格模板

```text
基于同一张[场景中文名称]纯空场景母版图和人物资产图[图一人物]、[图二人物]，生成3×3人物站位连续性九宫格，16:9横向总画布。全局场景、时间、天气、光线、固定物件和三维拓扑完全不变。人物数量固定为[人数]；[图一人物]固定在[中文位置]，[图二人物]固定在[中文位置]；视线关系为[视线关系]；行动方向为[行动方向]。九格只改变摄影机位置、朝向、高度、景别和焦段。人物只因透视和遮挡改变画面比例，不换位、不镜像、不新增、不消失、不变装。场景锚点必须与纯空场景母版逐格对应。使用Next Scene1至Next Scene9标题；文字不稳定时输出无字版后期叠字。无字幕、无水印、无Logo、无可读文字。
```

## 8. 动作道具九宫格模板

```text
基于同一张[场景中文名称]空间母版图、人物资产图[图一人物]和道具资产图[道具一]，生成3×3动作道具连续性九宫格，16:9横向总画布。全局场景、人物站位、道具真实位置、时间、天气、光线和空间拓扑完全不变，只表现一个动作链：[动作起点] → [动作接触] → [动作结果]。Next Scene1至Next Scene9依次表现：准备、开始、接触、进行、关键瞬间、结果、人物反应、道具局部特写、原位保持。道具可以被遮挡或裁切，但不能改变数量、尺寸、方向、材质和摆放位置；人物不能交叉换位或穿模。文字不稳定时输出无字版后期叠字。无字幕、无水印、无Logo、无可读文字。
```

## 9. 质量自检

生成或交付前至少检查三遍：

1. 空间检查：九格是不是同一个场景；固定物件的相邻关系、门窗墙体、道路方向和空间比例是否一致。
2. 机位检查：每格是否真的改变了摄影机；近景是否只是放大或裁切，而不是把物件移到镜头前。
3. 连续性检查：人物数量、服饰、站位、视线、动作方向、光线、时间、天气、标题和关键帧投喂关系是否前后对应。

常见失败处理：

- 物品漂移：回到纯空场景母版，补写固定物件相邻关系和三维拓扑。
- 某格物品消失：不要增加该格专属禁止项，检查是否属于合理遮挡；若不合理，重做全局机位定义。
- 九格全部像一个机位：减少“保持原位”类限制，明确每格的摄影机位移、朝向、高度和景别。
- 近景出现不可能的物件：改写为“只放大既有物件，不新增、不移动”，并改用该场景的单张母版参考图。
- 人物换位或数量变化：先生成无人物九宫格，再单独叠加人物站位九宫格。
- 严格连续性仍不稳定：使用纯空场景母版图作为主参考，九宫格只作为机位规划，不把整张九宫格直接喂给视频模型。
